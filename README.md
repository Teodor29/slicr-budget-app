# Slicr

A personal budgeting web app that allows users to set monthly income, create spending categories, and track expenses.

**Live demo:** https://slicr-budget-app.vercel.app/

<br>

<img alt="slicr" src="https://github.com/user-attachments/assets/40c8ca76-1452-4154-a391-5f9d456727d4" />

## Features

- **Monthly plan** - Set your income and a budget for each category
- **Overview** - See how much is left in total and per category, and browse previous months
- **Transactions** - Add, edit and delete expenses, with optional recurring transactions
- **New month** - Start a new month from your plan, with recurring transactions carried over
- **Currency** - Choose which currency symbol to display

## Technologies

- React
- TypeScript
- Tailwind CSS
- Vite

## Installation

To run the project locally:

1. Clone the repository:

```
git clone https://github.com/Teodor29/slicr-budget-app.git
cd slicr-budget-app
```

2. Install dependencies:

```
npm install
```

3. Start the development server:

```
npm run dev
```

The application runs on http://localhost:5173
